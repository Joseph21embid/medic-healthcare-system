# National Integrated Healthcare Information and Emergency Response System

This project is a final year PHP/MySQL web application for a centralized healthcare information and emergency response platform.

The system will be built gradually using:

- Procedural PHP with organized includes and module folders
- MySQL database
- HTML, CSS, Bootstrap, and JavaScript
- Optional React only for advanced interactive modules when necessary

## First Development Goals

1. Set up the project structure.
2. Design the database schema.
3. Build authentication and user roles.
4. Create patient, hospital, and administrator dashboards.
5. Add the major healthcare modules one after another.

## Development Decision

This first version will use procedural PHP because it is easier to follow while building the final year project. After the working system is complete, it can be rebuilt or refactored into OOP as a learning exercise.
